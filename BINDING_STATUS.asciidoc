= Binding Status
:toc:

Binding status of each namespace listed on https://schemas.microsoft.com/sqlserver/[Microsoft SQL Server XML Schemas]
(index page dated April 2014).
Namespaces are relative to `http://schemas.microsoft.com/sqlserver/`.

Schemas are not redistributable (Microsoft copyright, no license grant), so none is committed or packaged;
`mvn -N antrun:run@download-schemas` downloads them into the root `schemas/` (git-ignored) and verifies their SHA-256 (listed in `schemas/schemas.sha256`).
Files now served as all zero bytes are downloaded from a pinned Wayback Machine snapshot of the original instead (listed in `schemas/schemas.wayback`); each snapshot has the size of the served file.
The 2005/2008/2010 RDL schemas could be redistributed under the [MS-RDL] Open Specifications notice, but use the same mechanism for consistency.

== Naming

Each module is named after the `targetNamespace` of its schema (as written in the schema, which may differ from the index page):

[horizontal]
token:: `b` + the first 4 lowercase hex characters of SHA-256 of the exact `targetNamespace` (UTF-8, no trailing
newline) + `e`, e.g. `ba1b3e` for `http://schemas.microsoft.com/sqlserver/2004/07/showplan`
module directory / artifactId:: `sqlserver-xml-schema-binding-` + token
package / `Automatic-Module-Name`:: `io.github.jinahya.sqlserver.xml.schema.binding.` + token

----
printf '%s' "http://schemas.microsoft.com/sqlserver/2004/07/showplan" | shasum -a 256 | cut -c1-4
----

== Legend

[horizontal]
`done`:: module exists, sources generate, and round-trip tests pass
`wip`:: module exists, sources generate and a `JAXBContext` loads, but no sample-document round-trip test yet
`todo`:: not started
`skip`:: deliberately not bound (reason in *Notes*), e.g. the schema cannot be retrieved; a schema without a
`targetNamespace` is bound under the namespace listed on the index page
